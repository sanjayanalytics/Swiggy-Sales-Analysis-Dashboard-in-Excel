# 🍔 Swiggy Sales Analysis Dashboard in Excel

## 📌 Project Overview

This project is an **Interactive Swiggy Sales Analysis Dashboard** built entirely in **Microsoft Excel**. The dashboard transforms raw Swiggy sales data into meaningful business insights through dynamic visualizations, KPI tracking, and interactive filtering capabilities.

The objective of this project is to analyze sales performance, customer ratings, order trends, food preferences, and restaurant performance to support data-driven decision-making.

---

## 🎯 Key Business Objectives

* Analyze overall sales performance.
* Monitor order volume and average order value.
* Track customer ratings and rating counts.
* Identify top-performing states, cities, and restaurants.
* Understand food category preferences (Veg vs Non-Veg).
* Examine monthly and daily sales trends.
* Enable interactive analysis using slicers and navigation buttons.

## 📈 Key Insights

### Sales Performance

* Generated **₹53.01 Million** in total sales.
* Processed **197.43K orders**.

### Customer Behavior

* Average customer rating remained **4.34**.
* Veg food contributed **64%** of sales while Non-Veg contributed **36%**.

### Geographic Insights

* Bengaluru emerged as the highest sales-generating city.
* Multiple states contributed significantly to overall revenue.

### Restaurant Performance

* KFC, McDonald's, Pizza Hut, and Burger King were among the top-performing restaurants.

### Trend Analysis

* Sales remained relatively stable across months.
* Weekend sales were generally higher than weekday sales.
